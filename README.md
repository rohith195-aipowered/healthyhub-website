# The Healthy Hub — website concept

Premium, mobile-first storefront concept for The Healthy Hub, Kokapet, Hyderabad.

## Included
- Responsive green and ivory visual identity
- Cinematic hero section with video and image fallback
- Product categories and menu cards
- WhatsApp enquiry links
- Mobile-responsive layout

## Important demo notes
This is a concept preview, not an approved production site. Confirm product availability, current prices, delivery terms and copy with the business before launch. Product images and hero stock footage load from external sources. Replace the hero footage with the business's approved/generated branded video before final handover. Product enquiries open WhatsApp; this demo does not process payments or create backend orders.

## Deploy
Static HTML. Connect this repository to Vercel with no build command and output directory `.`.
